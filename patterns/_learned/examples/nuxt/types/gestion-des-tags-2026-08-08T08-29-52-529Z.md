# Exemple appris — types (nuxt)

> Fichier d'origine : `shared/types/tag.ts`
> Corrigé par Claude suite à une revue automatique.
> Contexte : Gestion des tags — Tag : id: number, name: string (min 4, max 255), createdAt: string — exporte aussi createTagSchema pour la création, sans id/createdAt

## Ce qui a été corrigé

Tag est dérivé de createTagSchema (sans id/createdAt) au lieu d'un schéma complet. Il faut un tagSchema complet dont on dérive Tag via z.infer, et createTagSchema séparé sans id/createdAt.

```
import { z } from 'zod';

export const tagSchema = z.object({
  id: z.number(),
  name: z.string().min(4).max(255),
  createdAt: z.string(),
});

export type Tag = z.infer<typeof tagSchema>;

export const createTagSchema = tagSchema.omit({ id: true, createdAt: true });

export type CreateTagInput = z.infer<typeof createTagSchema>;

```
