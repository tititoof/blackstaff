# Squelette : page Nuxt (.vue)

```vue
<script setup lang="ts">
// imports

// définition des meta de page (si nécessaire)
definePageMeta({
  // layout: false,
})

// state réactif

// computed

// fonctions / handlers
</script>

<template>
  <div>
    <!-- contenu -->
  </div>
</template>
```

Règles :
- `<script setup lang="ts">` toujours en premier
- `definePageMeta` seulement si explicitement demandé par la tâche
- Pas de section `<style>` sauf si demandé
