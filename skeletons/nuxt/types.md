# Squelette : fichier de types

```typescript
// app/types/xxx.ts
export interface IXxx {
  // champs typés
}
```

Règles :
- Préfixe `I` pour les interfaces si c'est la convention du projet (vérifier dans la description de la tâche)
- Un seul concept par fichier sauf si la tâche en demande explicitement plusieurs
