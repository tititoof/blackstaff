# Spécificités Nuxt 3

Dépend de [/frameworks/nuxt/nuxt.md](/frameworks/nuxt/nuxt.md).

- Racine du code applicatif directement sous `/` : `pages/`, `components/`,
  `composables/`, `server/`, `middleware/` sont à la racine du projet.
- Auto-imports actifs par défaut pour `composables/`, `components/`, `utils/`.

# Chemins à utiliser dans les recettes de patterns

| Concept | Chemin |
|---|---|
| Composable | `composables/use{Resource}s.ts` |
| Page liste | `pages/{resource}s/index.vue` |
| Route API | `server/api/{resource}s/index.get.ts` |
