# Spécificités Nuxt 4

Dépend de [/frameworks/nuxt/nuxt.md](/frameworks/nuxt/nuxt.md).

Différence structurelle majeure par rapport à Nuxt 3 : le code applicatif
côté client vit sous `app/`, le code serveur reste sous `server/` à la
racine.

# Chemins à utiliser dans les recettes de patterns

| Concept | Chemin |
|---|---|
| Composable | `app/composables/use{Resource}s.ts` |
| Page liste | `app/pages/{resource}s/index.vue` |
| Route API | `server/api/{resource}s/index.get.ts` |

# Pièges à éviter

- Générer une page sous `pages/` au lieu de `app/pages/` est l'erreur la
  plus fréquente d'un modèle entraîné majoritairement sur des exemples
  Nuxt 3. Toujours confirmer via `nuxtVersion` du contrat, jamais deviner
  depuis le nom du projet ou son package.json.
- La règle de conversion fichier → URL de `server/api/` ne change pas
  entre Nuxt 3 et Nuxt 4 — seul l'emplacement du code client change.
