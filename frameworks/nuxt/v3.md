# Statut de cette version

Nuxt 3 atteint sa fin de support le 31 juillet 2026 (plus de correctifs de
sécurité après cette date). Pour tout nouveau projet à partir de juin
2026, démarrer directement en [Nuxt 4](/frameworks/nuxt/v4.md) — cette
page reste utile uniquement pour maintenir un projet existant en attendant
sa migration.

# Racine applicative

Racine du projet (pas de dossier `app/` dédié).

# Résolution de chemins

| Élément | Chemin |
|---|---|
| Pages | `pages/` |
| Composants | `components/` |
| Composables | `composables/` |
| Stores Pinia | `stores/` |
| Middleware | `middleware/` |
| Plugins | `plugins/` |
| Layouts | `layouts/` |
| Types partagés | `types/` |
| Routes serveur (API) | `server/api/` |
| Assets statiques publics | `public/` |
| Tests unitaires | `tests/unit/` |
| Tests e2e | `tests/e2e/` |

# Alias

`~/` et `@/` pointent vers la racine du projet.

# Commande de création de projet

```bash
npx nuxi@latest init mon-projet
```

# Migration vers Nuxt 4

Voir [Nuxt 4 — chemins](/frameworks/nuxt/v4.md), section "piège spécifique
à la migration v3 → v4" pour le changement le plus fréquemment oublié
(résolution de l'alias `~/`).
