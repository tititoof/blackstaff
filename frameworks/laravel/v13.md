# Statut de cette version

Laravel 13 est sorti le 17 mars 2026, requiert PHP 8.3 minimum (PHP 8.4
recommandé en production, notamment pour les sous-versions 13.3+ qui
embarquent des dépendances Symfony 8). Laravel 12 reste en correctifs de
bugs jusqu'au 13 août 2026 — pour un nouveau projet à partir de
maintenant, démarrer directement en Laravel 13.

# Contexte structurel

La structure de dossiers est stable depuis le flattening de Laravel 11
(moins de fichiers de configuration et de middleware générés par défaut,
bootstrap centralisé). Laravel 12 et 13 conservent cette même structure —
pas de nouveau changement structurel majeur à ce jour.

# Résolution de chemins

| Élément | Chemin |
|---|---|
| Modèles | `app/Models/` |
| Controllers | `app/Http/Controllers/` |
| Form Requests | `app/Http/Requests/` |
| Routes API | `routes/api.php` |
| Config CORS | `config/cors.php` |
| Middleware (enregistrement) | `bootstrap/app.php` (plus de `app/Http/Kernel.php`) |
| Migrations | `database/migrations/` |
| Tests | `tests/Feature/`, `tests/Unit/` |

# Particularité Laravel 13

- **Attributs PHP de première classe** : `#[Middleware('auth')]`,
  `#[Authorize(...)]` directement sur les controllers/méthodes, en
  complément (pas en remplacement obligatoire) de la configuration par
  propriétés classique.
- **PHP 8.3 minimum**, contre 8.2 pour Laravel 12 — vérifier la version
  PHP du serveur cible avant de lancer une migration.

# Si migration depuis Laravel 10 ou antérieur

Le fichier `app/Http/Kernel.php` n'existe plus depuis la version 11 —
l'enregistrement des middlewares se fait dans `bootstrap/app.php` via
`withMiddleware()`.

# Commande de création de projet

```bash
composer create-project laravel/laravel mon-projet
```

# Outil de migration assistée

Laravel Shift automatise une grande partie des changements mécaniques
entre versions majeures (PR avec commits atomiques à relire) — pertinent
au-delà d'un projet trivial.
