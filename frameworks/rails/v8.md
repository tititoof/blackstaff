# Statut de cette version

Rails 8.1 est la version stable actuelle (patch 8.1.3, mars 2026). Rails
7.2 reste supporté en correctifs jusqu'en août 2026 — pour un nouveau
projet à partir de maintenant, démarrer directement en Rails 8.1.

# Résolution de chemins

| Élément | Chemin |
|---|---|
| Modèles | `app/models/` |
| Controllers | `app/controllers/api/v1/` (mode API) |
| Service objects | `app/services/` |
| Serializers | `app/serializers/` |
| Routes | `config/routes.rb` |
| Migrations | `db/migrate/` |
| Initializers | `config/initializers/` |
| Tests | `test/` (Minitest, structure miroir de `app/`) |

# Particularités Rails 8

- **Solid Queue / Solid Cache / Solid Cable** : remplacent Redis par
  défaut pour les jobs en arrière-plan, le cache, et Action Cable — adopté
  nativement depuis Rails 8.0. Ne pas ajouter Redis sauf besoin spécifique
  non couvert par ces solutions (ex. cache partagé multi-application).
- **Kamal** : outil de déploiement par défaut généré avec un nouveau
  projet Rails 8 (`config/deploy.yml`) — pertinent si le déploiement ne
  passe pas déjà par une autre solution (Docker Compose seul, k8s...).
- **Authentification native** : `bin/rails generate authentication`
  génère un système de session cookie classique — ne couvre pas le JWT
  pour API séparée, voir le pattern `auth` du bundle pour Devise +
  devise-jwt dans ce cas précis.

# Commande de création de projet (API-only)

```bash
rails new mon_projet --api --database=postgresql
```

# Commande de migration

```bash
rails db:migrate
```

Identique depuis de nombreuses versions majeures — pas de changement à
anticiper sur ce point précis en Rails 9.
