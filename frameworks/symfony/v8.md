# Statut de cette version

Symfony 8.1 est la version stable la plus récente (mai 2026), support
standard (8 mois de correctifs bugs+sécurité, jusqu'en janvier 2027).
Requiert PHP 8.4.0 ou supérieur. À choisir uniquement si le projet a
besoin des toutes dernières fonctionnalités et accepte un suivi de version
plus fréquent — sinon préférer [Symfony 7.4 LTS](/frameworks/symfony/v7.md).

# Résolution de chemins

Identique à Symfony 7.4 — aucun changement structurel entre les deux
branches sur ces emplacements :

| Élément | Chemin |
|---|---|
| Entités | `src/Entity/` |
| Controllers | `src/Controller/` |
| Voters | `src/Security/Voter/` |
| Config sécurité | `config/packages/security.yaml` |
| Migrations | `migrations/` |
| Tests | `tests/` |

# Compatibilité PHP

PHP 8.4.0 minimum — vérifier que l'environnement cible (serveur, image
Docker) tourne déjà sur PHP 8.4 avant de choisir cette version plutôt que
la 7.4 LTS (qui accepte PHP 8.2+).
