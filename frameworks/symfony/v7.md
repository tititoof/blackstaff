# Statut de cette version

Symfony 7.4 LTS, sortie en novembre 2025, est la version de référence par
défaut de ce bundle — correctifs de bugs jusqu'en novembre 2028, correctifs
de sécurité jusqu'en novembre 2029. C'est le choix recommandé pour un
nouveau projet sans contrainte spécifique nécessitant la toute dernière
version.

# Résolution de chemins

| Élément | Chemin |
|---|---|
| Entités | `src/Entity/` |
| Controllers | `src/Controller/` |
| Voters | `src/Security/Voter/` |
| Config sécurité | `config/packages/security.yaml` |
| Migrations | `migrations/` |
| Tests | `tests/` |

# Compatibilité PHP

Symfony 7.x requiert PHP 8.2 ou supérieur — moins contraignant que
Symfony 8.x (PHP 8.4 minimum), pertinent si l'environnement cible n'est
pas encore sur PHP 8.4.

# Commande de création de projet (version LTS explicite)

```bash
symfony new mon-projet --version=lts
# ou sans le binaire Symfony :
composer create-project symfony/skeleton:"7.4.*" mon-projet
composer require webapp   # si application web classique, à omettre pour une API pure
```

# Note de compatibilité de chemins

Cette structure de chemins est stable depuis Symfony 5+ — Symfony n'a pas
connu de refonte comparable à Laravel 11 ou Nuxt 4 sur ces emplacements.
Si une future version casse cette convention, créer un nouveau fichier
`v{N}.md` plutôt que d'éditer celui-ci rétroactivement.

# Si besoin de la dernière version plutôt que la LTS

Voir [Symfony 8.1](/frameworks/symfony/v8.md) — même structure de
chemins, mais PHP 8.4 minimum et fenêtre de support standard (8 mois) au
lieu de LTS.
